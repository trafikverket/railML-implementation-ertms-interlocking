= railML Element
:page-layout: default
:toc: macro
:toclevels: 2
:source-highlighter: highlight.js

For more information see the https://www.railml.org/files/download/schemas/3.2/documentation/railml3.html[railML 3.2 Documentation].

[source,xml]
----
<railML xmlns="https://www.railml.org/schemas/3.2" 
        xmlns:dc="http://purl.org/dc/elements/1.1/"
        xmlns:xsd="http://www.w3.org/2001/XMLSchema"
        xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
        xsi:schemaLocation="https://www.railml.org/schemas/3.2 https://www.railml.org/schemas/3.2/railml3.xsd"
        xmlns:trv="https://www.trafikverket.se/RailML/Extensions/ERTMSInterlocking"
        version="3.2">
...
</railML>
----

[cols="1,1,3", options="header"]
|===
|Attribute/Element |Requirement Level |Description

|Namespace definitions
|optional
|This is RECOMMENDED. +
The namespaces in the sample above **SHOULD** be defined in order to use the prefix to identify namespace reference.

|`trv` Namespace
|optional
|This is RECOMMENDED. +
Custom namespace for Trafikverket's extensions to the railML schema. +
The namespace **SHOULD** be defined in order to use the prefix to identify namespace reference.

|railML@version
|mandatory
|Always `3.2` since this implementation is based on railML 3.2.
|===
