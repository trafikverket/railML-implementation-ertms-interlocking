= Uses Types
:page-layout: default
:toc: macro
:toclevels: 2

The `usesTypes` element defines all type definitions used within railML.  
It serves as a catalog of reusable definitions that describe common behaviours and configurations — such as signal aspects, route types, and detector types — which are referenced by other interlocking objects.

Each type defined under `usesTypes` provides a standardized description that can be applied across multiple instances within the same interlocking configuration.

== hasAspect

== hasDetectorTypes

The `hasDetectorTypes` collection defines the **types of train detection elements** used within the interlocking.

[cols="1,1,3", options="header"]
|===
|railMLDetectorType(en) |DetectorType(sv) |Description
|avalanche |Lavindetektor |Detects avalanches which may endanger railway traffic.
|derailment |Urspårningsdetektor |Detects any derailed railway vehicle, often used near tunnels or bridges.detect unauthorized access.
|landSlide |Ras- och skreddetektor |Detects landslides or rockfalls that may endanger railway traffic.
|===
