= Object Positioning
:page-layout: default
:toc: macro
:toclevels: 2
:source-highlighter: highlight.js

All objects are positioned using intrinsic coordinates. +
The network is referenced with one of the following methods:

*	Spot location
**	The object is assigned a single point
* Linear location
** The object stretches over one or multiple net elements continuously without branching.
* Area location
** The object covers an area described by the included net elements.

== Spot Location

Used for objects whose position can be precisely defined by a single point on the railway network.

[source,xml]
----
<spotLocation id="lc86306e-f1b0-4b3f-8e3f-a3ea23691666" netElementRef="ne1972_2-1972_14-0" intrinsicCoord="0.04762" applicationDirection="both" pos="188.588">
  <geometricCoordinate positioningSystemRef="ge_01" x="7325788" y="876014" />
</spotLocation>
----

== Linear Location
Used for objects whose position is defined over a stretch of the railway network, spanning one or more net elements.

[source,xml]
----
<linearLocation id="5a52d7cb-6978-4037-873a-ed6976ee8f70" applicationDirection="both">
  <associatedNetElement netElementRef="ne1799.6.1799.7.1" intrinsicCoordBegin="0" intrinsicCoordEnd="1" keepsOrientation="true" posBegin="0" posEnd="903.243835" />
</linearLocation>
----

[cols="1,1,3", options="header"]
|===
|Attribute/Element |Requirement Level |Description

|linearLocation@id
|mandatory
|xref:railML/recuring-elements/common-conventions.adoc[See the Common Conventions page for more information.]

|linearLocation@applicationDirection
|mandatory
|mandatory for objects that have a directional validity. +
For objects without directional validity, it MUST be excluded.

|associatedNetElement
|mandatory
|See <<associatedNetElement>> for details.

|===


== Area Location
Used for objects that cover an area within the railway network. These objects encompass multiple net elements, which may not necessarily be contiguous, but together define the extent of the area covered by the object.

[source,xml]
----
<areaLocation id="82467914-fb6f-40cc-8ac8-53b1432fdbd7">
  <associatedNetElement netElementRef="ne1799.1.1799.2.0" intrinsicCoordBegin="0" intrinsicCoordEnd="0.043922" keepsOrientation="true" posBegin="0" posEnd="54.2159" />
  <associatedNetElement netElementRef="ne1799.1.1799.5.0" intrinsicCoordBegin="0" intrinsicCoordEnd="0.345523" keepsOrientation="true" posBegin="0" posEnd="54.2159" />
  <associatedNetElement netElementRef="ne1799.11.1799.1.0" intrinsicCoordBegin="1" intrinsicCoordEnd="1" keepsOrientation="true" posBegin="307.397269" posEnd="307.397369" />
</areaLocation>
----

[cols="1,1,3", options="header"]
|===
|Attribute/Element |Requirement Level |Description

|areaLocation@id
|mandatory
|xref:railML/recuring-elements/common-conventions.adoc[See the Common Conventions page for more information.]

|associatedNetElement
|mandatory
|See <<associatedNetElement>> for details.

|===

[[associatedNetElement]]
== Associated Net Element
Specifies individual network elements that are part of a linear or area location.

[cols="1,1,3", options="header"]
|===

|Attribute/Element |Requirement Level |Description
|associatedNetElement@netElementRef
|mandatory
|The reference to a specific network element that is part of the area location. This attribute links the area to a physical segment of the railway network.

|associatedNetElement@intrinsicCoordBegin
|mandatory
|Specifies the beginning intrinsic coordinate on the network element for the segment of the area. It defines where the segment starts within the network element.

|associatedNetElement@intrinsicCoordEnd
|mandatory
|Specifies the ending intrinsic coordinate on the network element for the segment of the area. It defines where the segment ends within the network element.

|associatedNetElement@keepsOrientation
|mandatory
|Indicates whether the orientation of the network element is preserved in the area location. This attribute is crucial for maintaining directional consistency.

|associatedNetElement@posBegin
|optional
|Assigned in meters from begining of net element. +
 +
The parties involved in the exchange should agree on an approach.

|associatedNetElement@posEnd
|optional
|Assigned in meters from begining of net element. +
 +
The parties involved in the exchange should agree on an approach.

|===
