== Trv:interface Rack

Represents an equipment rack within the signal box used for interface components.

[cols="10, 2, 4", options="header"]
|===
| XPath | Requirement Level | Description
| @trv:id | mandatory | Unique identifier for the interface rack (GSP-stativ).
| trv:interfaceRow | mandatory | Represents a row of interface terminals (GSP-Plintar) within the rack.
| trv:interfaceRow/@trv:id | mandatory | Unique identifier for the interface row.
| trv:interfaceRow/trv:interfaceTerminal | mandatory | Represents an individual interface terminal (GSP-Plint) point.
| trv:interfaceRow/trv:interfaceTerminal/@trv:id | mandatory | Unique identifier for the interface terminal (GSP-Plint).
| trv:interfaceRow/trv:interfaceTerminal/trv:name | mandatory | Descriptive name of the interface terminal (GSP-Plint).
| trv:interfaceRow/trv:name | mandatory | Descriptive name of the interface row.
| trv:name | mandatory | Descriptive name of the interface rack (GSP-Stativ).
|===
